How it works

Simple 4 step process — from document to answer!

College info — fees, hostel, exams, placements — is stored in an Excel sheet

🧠
Step 2

💬
Step 3

Student Asks

✅
Step 4

Instant Answer

The LLM writes a clear answer using only the retrieved rows of the dataset
